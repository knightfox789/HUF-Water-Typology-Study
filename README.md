# HUF Water Typology Study

Persistent working repository for the **HUF / DSC Water Typology Study**.

This repository is used as a durable research library so that analysis, decisions, chat outputs, methods, corrections, and new ideas can be recovered even if a ChatGPT conversation is lost.

## Working principle

Every substantial work session should leave a record in this repository:

1. **Chat/session record** → `library/01_CHAT_LOG.md`
2. **Research analysis and methodology notes** → `library/02_RESEARCH_ANALYSIS_CHAIN.md`
3. **New ideas / future enhancements** → `library/03_IDEAS_BACKLOG.md`
4. **Recovery state / next steps** → `library/04_CONTINUATION_AND_RECOVERY.md`
5. **Source-document register** → `sources/SOURCE_REGISTER.md`
